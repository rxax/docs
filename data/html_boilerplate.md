## HTML5 Boilerplate code

basic template:

```html
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title></title>
    <style type="text/css"></style>
    <script></script>
</head>
<body>

</body>
</html>
```
